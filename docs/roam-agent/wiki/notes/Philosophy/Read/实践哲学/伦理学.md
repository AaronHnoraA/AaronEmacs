## Summary

《伦理学》（Ethica in Ordine Geometrico Demonstrata）是荷兰哲学家斯宾诺莎创作的哲学著作，首次出版于1677年。《伦理学》全名为《用几何学方法作论证的伦理学》，该书用几何学的方法写成，认为只有凭理性的能力获得的知识才是最可靠的知识，人有天赋的知识能力，世界是可以认识的。《伦理学》从本体论、认识论开始，最后得出《伦理学》的最高概念自由，为人的幸福指明了道路。可以说，自由是斯宾诺莎哲学的核心和最终归宿。 斯宾诺莎是资本主义萌芽前期的反宗教哲学家, 该书历时十余年完成, 讲述了早起唯物主义无神论者对物质,精神等概念的探讨. 但是由于时代的局限性, 他仍有一些形而上学, 机械唯物主义的问题在里面,但是关注其时代贡献, 以及对后世的影响, 仍然是一本值得一读的哲学经典. 斯宾诺莎的伦理学思想对后来的哲学家如康德、黑格尔等产生了深远的影响, 他的无神论和唯物主义观点也为现代哲学的发展奠定了基础. 总的...
