## Summary

A Hermitian matrix is a complex square matrix that equals its own conjugate transpose. Equivalently, a matrix A∈Mn​(C) is Hermitian if A†\=A. In coordinates, this means Aij​\=Aji​​ for all 1≤i,j≤n. Hermitian matrices are the complex analogue of real symmetric matrices.
